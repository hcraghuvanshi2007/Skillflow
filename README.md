# SkillFlow Academy - Landing Page

A modern, fully-responsive learning platform landing page built with pure HTML, CSS, and JavaScript. Showcasing an online education platform with courses, instructors, and interactive components.

## 🚀 Features

### Core Sections
- **Hero Section** - Eye-catching headline with search functionality and call-to-action buttons
- **How It Works** - 4-step learning journey visualization
- **Featured Courses** - Grid display of 4 premium courses with pricing, ratings, and instructor details
- **Expert Instructors** - Showcase of industry-leading instructors with ratings and student count
- **Browse Categories** - 8 course categories with icons and course counts
- **Statistics** - Large impact numbers (2M+ learners, 500+ courses, 95% completion rate)
- **Newsletter Signup** - Email subscription section with gradient styling
- **Professional Footer** - Navigation links, social media, and company information

### Design Highlights
- **Responsive Grid Layouts** - Automatic adaptation from 1-column on mobile to multi-column on desktop
- **Smooth Hover Effects** - Interactive card transitions and button effects
- **Gradient Backgrounds** - Modern purple-to-dark blue color scheme
- **Mobile-First Approach** - Works seamlessly on all screen sizes
- **Accessibility** - Semantic HTML, proper contrast ratios, keyboard navigation
- **Performance** - Single-file design for fast loading, no external dependencies

## 📱 Responsive Design

- **Desktop (1200px+)** - Full multi-column grid layout
- **Tablet (768px - 1199px)** - Optimized grid with adjusted spacing
- **Mobile (< 768px)** - Single-column layout with touch-friendly buttons

## 🔧 Customization Guide

### Change Colors
Edit the CSS variables in the `<style>` section:
```css
:root {
    --primary-color: #6366f1;      /* Change primary color */
    --accent-yellow: #fbbf24;      /* Change accent */
    --text-dark: #1f2937;          /* Change text color */
    /* ... other variables ... */
}
```

### Update Course Data
Find the course cards section and modify:
- Course title and instructor name
- Badge text (Beginner/Intermediate/Advanced)
- Pricing information
- Rating and student count
- Course image gradient colors

### Add/Remove Sections
Each section is modular and can be:
- Duplicated for similar layouts
- Removed without affecting others
- Reorganized by moving HTML sections
